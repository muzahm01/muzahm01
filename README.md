## 🚀 About Me

Senior Software Test Engineer with **15+ years** in software testing and quality assurance. I specialise in **test automation frameworks, CI/CD pipelines, and cloud-based test infrastructure** for mobile (Android, iOS), backend, and firmware systems.

Right now at **OURA** I'm:

- 🤖 &nbsp;**Leading an AI-powered synthetic test-data & replay platform** — generates realistic user data on demand and runs automated validation across mobile, backend, and firmware, replacing test-data prep that used to be done by hand before every release.
- 🔍 &nbsp;**Building an AI CI failure-analysis tool** — categorises test failures with LLMs, writes root-cause summaries, and files them to the right tracker, cutting duplicate tickets and manual triage.
- 🧩 &nbsp;**Authoring reusable AI-agent tooling** — engineers run test-data and device-testing workflows from natural-language requests, no framework internals required.
- 🎓 &nbsp;**Acting as AI Champion** — running the internal training that brought AI-assisted testing into everyday use across engineering teams.
